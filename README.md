# intro-css
Material de estudo sobre o básico de Cascading Style Sheets

Neste repositório,abordamos os principais conceitos necessários para estilizar páginas **HTML** e compreender como o navegador interpreta e aplica regras de estilo.

## O que é o CSS?
**CSS (Cascading Style Sheets)** é a linguagem utilizada para definir a apresentação visual dos elementos      *HTML*

## Formas de aplicar o CSS
- CSS Inline
- CSS Interno
- CSS Externo
