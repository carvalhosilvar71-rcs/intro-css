O que é o CSS?

O CSS (Cascading Style Sheets) é uma linguagem de estilo utilizada para definir a apresentação de elementos HTML em uma página web.Ou Folhas de estilo em cascata

Sobre o CSS

O CSS é responsável por definir a organização do elementos, permitindo controlar a aparência e o layout de uma página web.

Como aplicar o CSS?

Existem três maneiras de aplicar o CSS em um documento HTML:

  • Inline: aplicando estilos diretamente nos elementos HTML usando o atributo "style".
  • Interno
  • Externo

O que da pra fazer com o CSS?

O CSS não serve apenas para colocar cor na página. Ele controla:

  • cores
  • fontes
  • tamanhos
  • espaçamentos
  • sombras
  • bordas
  • posicionamentos
  • responsividade
  • animações
  • transições

Aplicando o CSS Inline

Nessa abordagem, o CSS é colocado diretamente no elemento HTML através do atributo style

Aplicando o CSS Interno

Nessa abordagem, o CSS é aplicado dentro de uma tag <style> dentro do do documento HTML.

Aplicando o CSS Externo

Nessa abordagem, os estilos do CSS ficam concentrados em um arquivo separado.

Para conectar esse arquivo ao HTML, utilizamos o elemento de <link> no <head> da página.
